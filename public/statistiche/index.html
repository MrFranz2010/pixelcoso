Backup e trasferimento

Esporta i dati locali in un file JSON per conservarli o spostarli su un altro dispositivo. Il file può contenere preferiti, cronologia, progressi dei giochi, profili PolyTrack, raccolta musicale e altre impostazioni salvate in questo sito.

I dati restano sul dispositivo: non vengono caricati online. I salvataggi che alcuni giochi conservano in IndexedDB, come quelli dell’emulatore, non sono inclusi.
